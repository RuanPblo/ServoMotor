# ⚙️ Servo Motor — Arduino

Este repositório reúne dois projetos utilizando **Arduino e servo motor**, explorando diferentes formas de controlar a posição do servo.

## 📂 Projetos

### 🔧 Servo Motor

Projeto básico utilizando um **servo motor controlado pelo Arduino**.

O objetivo é demonstrar o funcionamento do servo e como controlar sua posição através da programação, fazendo com que ele se movimente para diferentes ângulos.

**Componentes utilizados:**

* Arduino
* Servo motor
* Jumpers
* Protoboard

---

### 🎛️ Servo Motor e Potenciômetro

Neste projeto, um **potenciômetro é utilizado para controlar a direção do servo motor**.

O Arduino realiza a leitura do valor fornecido pelo potenciômetro e o converte em um ângulo correspondente. Dessa forma, ao girar o potenciômetro, o servo motor acompanha o movimento, alterando sua posição.

**Componentes utilizados:**

* Arduino
* Servo motor
* Potenciômetro
* Jumpers
* Protoboard

### ⚙️ Funcionamento

1. O potenciômetro fornece um valor analógico ao Arduino.
2. O Arduino realiza a leitura desse valor.
3. O valor é convertido para uma faixa de ângulos.
4. O servo motor se movimenta de acordo com o valor obtido.
5. Ao girar o potenciômetro, a posição do servo é alterada.

## 🎯 Objetivo

Os projetos têm como objetivo praticar o controle de **servomotores com Arduino**, além de demonstrar a utilização de entradas analógicas para controlar componentes eletrônicos.

## 🧰 Tecnologias

* Arduino
* C/C++
* Servo Motor
* Potenciômetro
